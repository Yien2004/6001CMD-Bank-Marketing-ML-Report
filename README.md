1. Project Overview
This repository contains the machine learning preprocessing pipeline for the UCI Bank Marketing dataset (45,211 rows, 16 features). The task is a supervised binary classification problem predicting whether a client subscribes to a term deposit, addressing key challenges such as severe class imbalance (88.3% vs. 11.7%) and high feature skewness.
2. Repository Files
6001CMD_Assignment_Pipeline.ipynb: Full executable notebook covering exploratory analysis, preprocessing, feature selection, and class-balancing benchmarks.
bank-full.csv: UCI Bank Marketing dataset.
README.md: Project summary and execution steps.
